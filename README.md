# 3D Cabinet Configurator

A real-time 3D cabinet configurator built with Vite, React, TypeScript, React Three Fiber (R3F), @react-three/drei, and Tailwind CSS.

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
cd frontend
npm run build
```
